Native 64-Bit & 32-Bit Win32 PE Resource Manipulation Suite

Resource Alchemy Hacker (ResourceAlchemist_PE_Editor-Extractor) is a native C++ Win32 suite inspired by classic Resource Hacker — compiled for both native x64 (no Sysnative WOW64 redirection headaches when inspecting System32 binaries) and x86, combining a TreeView GUI, headless CLI, and Windows Explorer COM context-menu integration.

Win32 GUI Inspector GUI

  • Inspects .exe, .dll, and .mun resources (RT_ICON, RT_STRING, RT_DIALOG, RT_VERSION, AVI, and binary blocks).
  • Configurable TreeView icon sizing and toggleable [Base], [MUN], and [MUI] origin tags.
  • Optional pre-edit automatic backup copies plus Authenticode signing support via custom .pfx certificates.

Headless Automation CLI CLI

  • Scriptable native Win32 C++ CLI (ResourceAlchemyHacker_CLI) built from the shared MSBuild solution.
  • Designed for repeatable batch PE resource extraction, icon group parsing, and replacement in build pipelines.
  • Shared structured logging at %SystemDrive%\EliteSoftware\Logs\ResourceAlchemist.log.

Explorer Shell Extension COM

  • Native IContextMenu and IShellExtInit shell extension (ResourceAlchemyHacker_ShellExt).
  • Adds direct right-click context menu launch on PE binaries in Windows Explorer.
  • Stores preferences under HKCU\Software\EliteSoftware\ResourceAlchemyHacker and INI profiles.
